= Mettez à jour les identifiants vCenter configurés dans SCV
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilisez cette tâche pour mettre à jour les identifiants de connexion vCenter configurés dans le plug-in SnapCenter pour VMware vSphere. SCV utilise ces identifiants pour accéder à vCenter. Lorsque l’identifiant vCenter change, mettez-le à jour dans SCV afin que vCenter reste enregistré auprès de SCV. Pour les sauvegardes vVol, désenregistrez ONTAP tools for VMware vSphere puis réenregistrez ONTAP tools avec le nouveau mot de passe afin que les sauvegardes continuent de fonctionner.

.Avant de commencer
Vous devez connaître l'adresse IP et les informations de connexion pour l'interface utilisateur de gestion du SnapCenter Plug-in for VMware vSphere .  Vous devez également noter le jeton MFA généré à partir de la console de maintenance.

* L'adresse IP était affichée lors du déploiement du plug-in SnapCenter pour VMware vSphere.
* Utilisez les informations d'identification fournies lors du déploiement du plug-in SnapCenter pour VMware vSphere ou telles que modifiées ultérieurement.
* Générez un jeton MFA à 6 chiffres à l'aide des options de configuration du système de la console de maintenance.


.Étapes
. Connectez-vous à l'interface utilisateur de gestion du SnapCenter Plug-in for VMware vSphere .
+
Utiliser le format `\https://<appliance-IP-address>:8080`

. Dans le volet de navigation de gauche, sélectionnez *Configuration*.
+
image:scpivs44_image30.png["SnapCenter Plug-in for VMware vSphere"]

. Sur la page *Configuration*, dans la section *vCenter*, sélectionnez *Modifier*.
. Entrez le nouveau mot de passe, puis sélectionnez *Enregistrer*.
+
Ne modifiez pas le numéro de port.



.Une fois que vous avez terminé
Après avoir enregistré les nouveaux identifiants, vérifiez que SCV est toujours connecté à vCenter.

* Dans l’interface utilisateur de gestion du plug-in SnapCenter pour VMware vSphere, ouvrez *Dashboard* et vérifiez que SCV est connecté à vCenter et activé.
* Dans le vSphere Client, vérifiez que le menu *SnapCenter Plug-in for VMware vSphere* s'affiche et que les pages du plug-in se chargent.
* Facultatif : Ouvrez un groupe de ressources ou exécutez une sauvegarde à la demande pour vérifier que les opérations vCenter fonctionnent.


Si SCV n'est pas connecté après la modification de l'identifiant, redémarrez le service client VMware vSphere. Si SCV n'est toujours pas connecté, accédez à link:scpivs44_post_deployment_required_operations_and_issues.html["Opérations requises et problèmes après le déploiement du SCV"].
